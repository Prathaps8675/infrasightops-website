Deployment Guide

Deploy InfraSightOps in Under 3 Minutes

Single-command, self-extracting installer. No Docker, no Kubernetes, no cloud dependency. Runs directly on bare-metal or VM Linux servers.

Step 1: Install InfraSightOps Master Application

Download and run the self-extracting installer as root on your designated Master Linux Server:

chmod +x infrasightops-installer.run && sudo ./infrasightops-installer.run
✔ Self-extracting closed-source application bundle (infrasightops-installer.run).
✔ Auto-installs Nginx reverse proxy, Gunicorn WSGI server, Python virtualenv at /opt/infrasightops.
✔ Installs paramiko for Remote SSH Executor module support.
✔ Registers infrasightops.service as a systemd daemon with auto-start on reboot.
✔ Web UI accessible immediately at: http://<MASTER_IP>:8088

Step 2: Deploy Client Agent on Target Servers

Copy and run the standalone agent binary on any Linux client server (RHEL, Ubuntu, Debian, Oracle, SUSE, Amazon Linux):

sudo ./infrasightops-agent
✔ Ships as a pre-compiled binary — source code is completely hidden from client server operators.
✔ Prompts for Master Server IP/URL on first run; saves config to /etc/infrasightops-agent.conf.
✔ Performs full health scan and uploads HTML, TXT, and JSON reports to Master.
✔ Subsequent runs use saved config automatically (no re-prompting). Ideal for unattended cron execution.

Step 3: Schedule Automated Periodic Health Scans

Add to root's crontab to schedule automatic daily health scans at 2:00 AM:

0 2 * * * /usr/local/bin/infrasightops-agent >/dev/null 2>&1
✔ Reports upload automatically to the Master dashboard — no manual intervention needed.
✔ Adjust schedule frequency as needed: hourly, daily, weekly, or post-maintenance window.
✔ Set multiple cron entries to capture pre-maintenance and post-maintenance snapshots for drift detection.

Step 4: Remote SSH Executor, Web Terminal & Multi-Server Orchestrator

Directly from the web UI, audit, manage, and execute automated pipelines across your Linux fleet:

✔ 1-Click Health Check Push: Push and execute health_check.sh on target servers via password or SSH private key with live terminal streaming.
✔ Interactive Web SSH Terminal: Direct browser-based SSH terminal with real-time output, command history, and seamless sudo root switching.
✔ Multi-Server Orchestrator: Run bulk multi-line bash scripts across hundreds of servers with Rolling Serial (1-by-1) or Parallel Concurrent strategies.
✔ Automated Verification Pipelines: Run Precheck, Main Command, and Postcheck stages with side-by-side diff matrix and Stop on first failure protection.
✔ Secure Encrypted Vault: Store SSH credentials and private keys locally with automatic host-matching and commercial capacity governance.

Got Questions?

Frequently Asked Questions

Everything you need to know about licensing, deployment, offline execution, security, orchestrator, and support.

Does license validation work on offline / air-gapped Master Servers?
Yes, 100%. Validation runs locally using cryptographic HMAC signatures with zero external API calls or phone-home pings. It operates reliably in classified networks, isolated VPCs, and secure air-gapped data centers.
How does the Multi-Server Orchestrator work compared to Ansible or SaltStack?
InfraSightOps requires no client agents and no Python dependencies. Execute multi-line scripts across fleets with concurrent parallel or rolling serial modes and automated stop-on-failure safety checks directly from the browser.
Can client servers upload reports over a Private IP without internet access?
Yes. Nodes post scan telemetry directly to the Master Server's Private IP (e.g., http://10.0.27.53:8088/upload) via standard curl. No public IP or internet routing is required.
Are stored SSH passwords and private keys secure in the Credential Vault?
Yes. All credentials and SSH keys (RSA/ED25519) are AES-encrypted in a local database on the Master server. They are never exported or transmitted externally, and access is enforced by strict RBAC policies.
What happens when a commercial license reaches its expiration date?
Your instance enters a 14-day grace period with full scanning capability. Afterward, upload capacity reverts to the 10-node Community limit. All historical scan reports and diffs remain permanently accessible.
Does the client agent run continuously as a background daemon?
No. The agent is a lightweight on-demand binary that executes and terminates immediately. It consumes 0% RAM and 0% CPU when idle, leaving no background daemons or open listening ports.
How does client organization and project scope binding work in licenses?
Licenses are digitally signed for your specific Organization Name, Project Scope, and optional Master machine-id, ensuring strict compliance and preventing unauthorized deployment transfer.
Will reinstalling or upgrading InfraSightOps remove my existing license?
No. The installer automatically preserves your commercial license key, database, and historical reports across upgrades. Running ./infrasightops-installer.run is safe to repeat without data loss.
